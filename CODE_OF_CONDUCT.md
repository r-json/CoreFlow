# Code of conduct

CoreFlow Kit follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and assume good faith.
- Welcome newcomers, and keep criticism about the work, not the person.
- No harassment, discrimination, personal attacks or publishing other people's private information.

## Scope

This applies in the repository's issues, pull requests, discussions and reviews,
and wherever someone represents the project.

## Reporting

Report unacceptable behaviour privately to the maintainer, using the contact
details on the [maintainer's GitHub profile](https://github.com/r-json). Reports
are handled confidentially. The maintainer may remove comments, lock threads or
block participants who break this code, as the Contributor Covenant describes.
